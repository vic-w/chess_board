用freecad画一个挂式的国际象棋棋盘。挂在墙上，设计要优雅有美感。
每一层格子下面都有一层小平台，用来摆放棋子。棋子还用到买来的立体磁性棋子。平台之间的空间要足够高，够摆下最高的棋子：国王。我的国王高度是50mm，直径20mm。
用黑白两种颜色组成。且不用ams，黑和白分开打印。
每一格要放下一个真实的立体棋子。每个格是一个长方形 28 * 56 mm。由于平台也要占用高度，所以整个棋盘也是一个比例大于2：1的长方形。
棋子放在每一层格子下面的平台上。平台宽度刚刚好能容纳棋子的直径。平台宽度可以刚好设置成20mm。磁铁在平台的中间位置。
平台的两条长的棱需要有倒角。
由于需要由拓竹A1 mini打印，打印不下整个棋盘，所以要分块来打印。
每块横向4格，纵向2格。共分8块。每块由黑色作为主框架，包含黑色的平台来摆放棋子。8个模块复用相同的图纸。要有挂钩位置，可以挂在墙上。块与块之间用蝴蝶形卡扣连接。
白色的方块单独打印，再嵌入到黑色框架中。框架本身就包含了黑色块，不需要单独打印黑色块。
平台上有64个直径4mm深度4mm的孔，可以嵌入磁铁。辅助固定棋子。
最后要给出美观的拼装手册
黑格和白格之间不要有隔断，平台要连续不要断开，也不需要有栏杆。
黑色框架要考虑打印的可行性，不能有薄片状结构。
需要一个"last move"标识牌，挂在平台上，要避开棋子的圆柱体。正面有last move字样。可以从上下卡住平台。
还需要一个在底部装棋子的小盒，利用蝴蝶卡扣挂在整个棋盘下面
